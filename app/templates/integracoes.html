Como configurar
  1. Na consola do Google Cloud: APIs e serviços → Ativar a API do Gmail → Credenciais → Criar ID de cliente OAuth → Aplicação web.
  2. Regista como endereço de redirecionamento autorizado exatamente o valor no campo abaixo (acompanha a porta que estiveres a usar).
  3. Cola aqui o ID de cliente e o segredo, guarda, e usa 「Ligar conta Gmail」. A chave de API do Gmail não é necessária: usamos só OAuth.
